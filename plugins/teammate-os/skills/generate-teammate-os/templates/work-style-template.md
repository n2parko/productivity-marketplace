# Work Style

## Communication Style

- **Only ask for clarification if highly ambiguous** — synthesize and make reasonable assumptions
- Lead with answer first, then explain thinking
- Exec-level communication with ability to go deeper in bullets
- Don't ask questions that can be inferred from context
- Start with conclusion → reasoning → bullet details

## Documentation Structure

### Meeting Notes & Talking Points
- Markdown with clear hierarchy
- "Summary of the Ask" section at top
- "Executive Summary" for quick overview
- "Internal Notes (do not share)" section for sensitive info
- "Open Questions" section with numbered list
- "Proposed Next Steps" with action items and timelines

### Status Tracking
- Emoji indicators: ✅ Complete, 🟡 In Progress, 🔴 Blocked
- Status tables: Component | Status | Timeline
- Priority levels: P0, 🔴 High, 🟡 Medium, 🟢 Normal, 🔵 Lower

### File Organization
- By date: `todos/YYYY-MM-DD/todo.md`
- Customer work: `customers/{customer-name}/`
- Project work: `projects/{project-name}/`
- Descriptive filenames with dates: `YYYY-MM-DD-talking-points.md`
- `next-steps.md` in project folders for action items

## Task Management

### Todo Structure
- Checkbox format: `- [ ] Task description`
- Group by priority with emoji headers
- Scheduled items in table format with dates
- Assign to people: `(Person A + Person B)`
- Sub-bullets for details

### Action Items
- Extract from meeting notes into `next-steps.md`
- Break down by category
- Include owner assignments

## Meeting Preparation

### Before Meetings
- Create talking points document
- Include executive summary for quick reference
- List open questions with current understanding
- Separate internal concerns from shareable content
